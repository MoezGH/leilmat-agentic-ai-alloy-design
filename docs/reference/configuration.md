# Configuration reference

> Generated by `scripts/gen_reference_docs.py` — do not edit by hand. Run `python scripts/gen_reference_docs.py` after changing the code.

Settings are read from environment variables (or a `.env` file in the working directory); names are case-insensitive. Copy [`.env.example`](../../.env.example) to `.env` to start. Everything beyond the database, ChromaDB and (optionally) an LLM key is an **optional integration that is off unless configured** — see [Deployment](../deployment.md).

Defaults shown are the values in source. Secrets default to empty.

## Daytona cloud compute (grain-structure tier)

| Variable | Type | Default | Description |
|---|---|---|---|
| `DAYTONA_API_KEY` | `str` | `''` | When `daytona_api_key` is blank the whole cloud-compute feature is DARK: the /api/compute/* endpoints return 503 and the reaper never starts. |
| `DAYTONA_SNAPSHOT_NEPER` | `str` | `''` | Pre-baked snapshot id with Neper + POV-Ray compiled in (built once via apps/api/compute/snapshots/neper.py). |
| `DAYTONA_DAILY_BUDGET_USD` | `float` | `10.0` | Always-on cost guardrails, enforced server-side regardless of the (currently dormant) LeilAI-5 credit system, because real money is spent the moment a sandbox runs. hard daily spend ceiling (long jobs) |
| `DAYTONA_MAX_CONCURRENT_JOBS` | `int` | `2` | parallel sandbox cap |
| `DAYTONA_JOB_WALL_CAP_S` | `int` | `900` | default per-job hard kill (15 min) |
| `DAYTONA_USD_PER_VCPU_HOUR` | `float` | `0.1` | Cloud-job billing. |
| `CLOUD_COST_MARKUP` | `float` | `3.0` | same 3× markup as LLM token cost / LeilCFD |
| `CREDITS_PER_DOLLAR` | `int` | `100` | MUST match LeilAI-5 CREDITS_PER_DOLLAR |
| `DAYTONA_SNAPSHOT_SPPARKS` | `str` | `''` | Pre-baked SPPARKS snapshot (built once via apps/api/compute/snapshots/spparks.py). |
| `DAYTONA_GROW_WALL_CAP_S` | `int` | `7200` | SPPARKS grain growth is a legitimately long Monte-Carlo run. |
| `SPPARKS_MPI_RANKS` | `int` | `4` | SPPARKS runs MPI-parallel (spk_mpi + mpirun -np N) for near-linear multi-core speedup (~5× at np=4, measured). |
| `DAYTONA_SNAPSHOT_DAMASK` | `str` | `''` | Pre-baked DAMASK snapshot (crystal-plasticity FFT solver via conda-forge damask-grid + python-damask; built once by compute/snapshots/damask.py). |
