# API reference

> Generated by `scripts/gen_reference_docs.py` — do not edit by hand. Run `python scripts/gen_reference_docs.py` after changing the code.

46 endpoints in 12 groups. With the server running, interactive documentation (try-it-out, full request/response schemas) is served at `/docs`, and the machine-readable schema at `/openapi.json`.

Cost-bearing endpoints can be gated by authentication and a credit check; see [Architecture](../architecture.md#request-pipeline) and [Deployment](../deployment.md#security-checklist). With no auth configured the API runs open.
